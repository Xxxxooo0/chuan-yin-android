# GVC-RT Small Local Model Snapshot

This directory is committed only on the local `GVC-RT-S-models`
branch. Do not push this branch to Gitee.

- `gvc-rt-small_tflite_codec_270p_qp0_with_inputs.tar.gz`: three TFLite models and fixed test inputs.
- `gvc-rt-small_dla_codec_270p_qp0_with_inputs.tar.gz`: compiled DLA models and fixed test inputs.
- `gvc-rt-small_precision_270p_qp0.tar.gz`: server precision reference vectors.
- `gvc-rt-small_server_original.tar.gz`: original server-side Small package snapshot.

The deployment is fixed to 256x512 (270p padded working size) and QP 0.
